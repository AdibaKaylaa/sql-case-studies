# sql-case-studies
Solutions to Danny's Diner and Pizza Runner

I worked with realistic business datasets to have an idea about the kinds of questions a stakeholder would want to know about his business

## Case Studies

**Danny's Diner** —  a customer behaviour analysis for a small restaurant

**Pizza Runner** — a messy real-world dataset requiring data cleaning
before analysis

## Concepts used

- Joins across multiple tables
- Aggregation and `GROUP BY`
- Window functions (`DENSE_RANK`, `PARTITION BY`)
- Common Table Expressions (CTEs)
- Conditional logic (`CASE WHEN`)
- Data cleaning on inconsistent and null values

## Files

- `Danny_s_Diner.sql` — solutions for case study 1
- `Pizza_Runner.sql` — solutions for case study 2
